AID UR HEALTH – Real-Time Pandemic Alert & Response System
AID UR HEALTH is a modern healthcare monitoring and pandemic response platform developed to support real-time public health tracking, outbreak awareness, and emergency coordination across India. The project was designed with a focus on responsive user experience, live analytics visualization, and streamlined communication between citizens and healthcare services.
The platform provides an interactive dashboard that displays pandemic-related insights such as active cases, vaccination coverage, recovery statistics, and testing data across major cities. It also includes rapid outbreak reporting, healthcare service modules, and a contact/appointment management system integrated through Google Forms for efficient data collection and response handling.
The application emphasizes scalability, clean UI/UX design, and accessibility while delivering real-time visual insights using modern frontend technologies and chart-based analytics.
Core Features


Real-Time Pandemic Dashboard
Displays live statistics including active cases, vaccination rates, recoveries, and testing metrics with dynamic visual updates.


City-Wise Analytics & Visualization
Interactive charts and graphs for monitoring pandemic trends across multiple Indian cities.


Outbreak Reporting System
Enables users to report suspected outbreaks and emergencies through an integrated reporting workflow.


Healthcare Services Module
Includes rapid testing, vaccination tracking, and outbreak response sections to simulate public health service coordination.


Google Forms Integration
Implemented form-based appointment/contact management with automated submission handling and custom field mapping.


Responsive & Modern UI
Designed a clean and professional interface optimized for desktop, tablet, and mobile devices.


Reusable Component Architecture
Built modular frontend components for maintainability, scalability, and easier future enhancements.


Technologies Used

Integration: Google Forms API / Form Actions
